# SumatraPDF-NVDA

Доступная модификация читалки **SumatraPDF** для Windows со специальным текстовым режимом для экранных дикторов (**NVDA**, **JAWS** и др.).

---

## О проекте

В стандартной SumatraPDF книги и документы рисуются на графическом холсте, из-за чего программы экранного доступа не могут читать текст стрелками.

В **SumatraPDF-NVDA** графический холст заменён на стандартное многострочное текстовое поле Windows (`Win32 Edit`), в которое автоматически извлекается и форматируется весь текст открытой книги от первой до последней страницы. Это позволяет комфортно читать книги в форматах **PDF, DjVu, EPUB, FB2, MOBI, PRC, TXT, CHM, XPS, CBZ, CBR** с помощью обычных клавиш навигации NVDA без сторонних конвертеров и повторного распознавания (OCR).

---

## Основные возможности

- **Полная поддержка экранных дикторов (NVDA / JAWS):** мгновенное чтение по строкам, словам, символам и абзацам стандартными стрелками клавиатуры.
- **Загрузка всей книги целиком:** книга открывается полностью от первой до последней страницы в едином текстовом буфере без обрывов.
- **Умная склейка абзацев и очистка старого OCR на лету:**
  - автоматическое объединение строк, разорванных переносами внутри абзаца;
  - автоматическое удаление задвоенных первых слогов на переносах строк, характерных для старых сканов DjVu и PDF (с интеллектуальной проверкой совпадения слогов).
- **Выделение и копирование текста:** полноценная работа стандартных сочетаний `Shift+Стрелки`, `Ctrl+Shift+Стрелки`, `Ctrl+A` и `Ctrl+C` прямо в текстовом поле.
- **Автофокус на текст:** при переключении окон через `Alt+Tab` фокус автоматически возвращается прямо в текст книги на то же место без необходимости нажимать `Tab`.
- **Никаких фоновых логов:** программа не создаёт дополнительных файлов слежения при чтении текста.

---

## Управление и горячие клавиши

- **`Ctrl+O`** — Открыть файл (PDF, DjVu, EPUB, FB2, MOBI, TXT, CHM и др.)
- **`Стрелки Вверх / Вниз`, `Влево / Вправо`** — Чтение текста по строкам и символам
- **`Ctrl+Вверх / Вниз`, `Ctrl+Влево / Вправо`** — Перемещение по абзацам и словам
- **`Shift+Стрелки`, `Ctrl+A`, `Ctrl+C`** — Выделение фрагмента или всего текста и копирование в буфер обмена
- **`PageDown / PageUp`** — Быстрое листание текста (или переключение страниц в постраничном режиме)
- **`Ctrl+PageDown / Ctrl+PageUp`** — Переход ровно к следующей или предыдущей странице
- **`Ctrl+G`** — Переход к странице по её номеру
- **`Ctrl+F`** — Поиск слова или фразы по книге (`F3` — следующее совпадение, `Shift+F3` — предыдущее совпадение, `Esc` — вернуться к тексту)
- **`F8`** — Переключение режима форматирования строк:
  - *Умные абзацы* (склейка переносов и очистка задвоенных слогов OCR);
  - *Оригинальные строки страницы* (как в исходном документе).
- **`F9`** — Переключение режима загрузки:
  - *Вся книга целиком* (по умолчанию);
  - *Постраничный режим* (отображение только текущей страницы).
- **`Alt`** — Главное меню программы (свойства документа, чтение вслух, закладки, настройки).
- **`1–9` или `Enter` на стартовом экране** — Быстрое открытие книги из списка недавних.
